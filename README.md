## 历史：叽咕插画 V0

把今天的小故事，画下来。

上传 1–6 张宝宝照片，说一句今天发生了什么，程序先把五页文字整理出来给你改，确认后才调用 Seedream 逐页画成 3:4 的彩色小绘本。手机浏览器打开，左右翻页，可以改文字、可以单页重画、可以整本导出。

V0 只服务一个场景：**私有自用，真实照片 + 真实经历，五页彩色绘本**。

---

## 三个硬约束

1. **只在本地跑。** 服务端默认监听 `127.0.0.1:7860`，照片、作品、数据库都在本机 `data/` 里，不上传任何第三方存储（画图时照片以 Base64 直接发给火山方舟，不经过公网图床）。
2. **API Key 只在服务端。** 从环境变量 `ARK_API_KEY` 或本地 `data/.env` 读取，不进前端、不进日志（日志只打掩码）、不落库、不进仓库。
3. **真实照片和作品不入库。** `.gitignore` 已排除整个 `data/`，仓库里只有代码。

## 快速开始

```bash
cd jigu-picturebook
python -m venv .venv            # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 配 Key（二选一）
setx ARK_API_KEY "你的火山方舟 Key"        # 或者写进 data/.env
# data/.env 内容：ARK_API_KEY=你的Key

python run.py
```

打开 http://127.0.0.1:7860 ，手机连同一个 Wi-Fi 时也可以用电脑内网 IP 打开（`JIGU_HOST=0.0.0.0`，但这会把服务暴露给局域网，自己权衡）。

启动时会做一次**零成本**的模型探测（只发 model 字段，不产生图片），在终端打印当前可用的模型和单价。

### 第一次用

1. 首页点「开始做小书」。
2. 上传 2–4 张宝宝照片（能看清脸和当天的衣服最好）。
3. 填「今天发生了什么」→「当时的感受」→「特别想记下来的细节」→「宝宝称呼」。
   想直接复现第一本，点「填入示例：《我是国王先生！》」。
4. 点「下一步」，检查五页文字和画面描述，可以直接点着改。
5. 点「确认，开始画」，5 页并行排队画，约 70–90 秒。
6. 画完自动进阅读页：左右滑动翻页，可以改单页文字、重画单页、导出整本。

## 目录结构

```
jigu-picturebook/
├── run.py                 启动入口（Flask app、大小限制、启动横幅）
├── server/
│   ├── config.py          路径 / 模型 / 预算 / 密钥
│   ├── db.py              SQLite（books / pages / uploads / calls）
│   ├── ark.py             火山方舟 Images API 封装、错误翻译、模型探测
│   ├── prompt.py          四段式提示词 + 五页机位
│   ├── story.py           把家长的话整理成五页文字（纯规则，不依赖大模型）
│   ├── presets.py         《我是国王先生！》确认稿
│   ├── compose.py         1500×2000 排版、PDF、ZIP 导出
│   ├── worker.py          后台生成、预算保护、单页重画
│   └── api.py             HTTP 接口
├── web/                   移动端单页（原生 JS，无构建）
├── tools/
│   ├── e2e_test.py        端到端跑一本（会真实花钱）
│   └── check_pdf.py       校验导出 PDF 结构
├── docs/                  GitHub Pages 静态介绍页
└── data/                  本地数据（不进仓库）
    ├── .env               Key
    ├── books.db           元数据
    ├── uploads/           上传的照片（已剥离 EXIF）
    ├── books/<id>/        每页原图与排版稿
    └── tmp/               导出 ZIP 与临时图
```

## 模型与计费

| 模型 | 3:4 尺寸 | 单价 |
| --- | --- | --- |
| `doubao-seedream-5-0-flash-260915`（默认） | 1776×2368 | ¥0.12/张 |
| `doubao-seedream-4-0-20260415` | 1728×2304 | ¥0.20/张 |

一本五页 = 5 张图，flash 约 ¥0.60；重画一页 +¥0.12。参考照片不计费。

模型 ID 会变，所以不写死：启动时按 `JIGU_MODEL` → flash → pro → 4.0 → 4.5 → lite 顺序探测，用第一个能用的，并把结果打在横幅和 `/api/health` 里。

整站有累计预算保护（`JIGU_BUDGET_CNY`，默认 10 元），超了直接拒单，不会闷头烧钱。

## 隐私

- 上传时用 Pillow 重新编码，**剥离 EXIF**（GPS、设备信息都丢掉），长边压到 2400。
- 照片只存在于本机 `data/uploads/` 和发给方舟的那一次请求里。
- 删除作品会连同图片文件一起删，不留软链。
- 导出是本地生成的 ZIP（5 张排版稿 + PDF + 文字 txt + book.json），不经过任何云端。
- 旧的泄露 Key 需要自己去火山控制台轮换，这个仓库里没有任何 Key。

---

## 已知边界（V0 不做）

- **不能公网部署**：这是带 Key 的服务端，GitHub Pages 只能托管静态页（`docs/` 是产品介绍页，不是应用本体）。
- 没有自动质检：宝宝像不像、场景对不对，由家长看过再决定要不要重画。
- 只有一种画风（彩色绘本），没有语音、打印、支付、社区、多宝宝。
- 文字整理是规则版：能保证不瞎编事实，但措辞不如大模型自然，所以预览页留了「点着改」。
