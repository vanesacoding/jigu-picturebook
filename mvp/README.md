# 叽咕插画 · 本地私有 MVP

把今天的小故事，画下来。

这是一套可运行的前后端应用，不是静态页面。后端保存账号、照片、故事、任务、图片版本和费用预留记录；前端为手机 H5。真实调用代码只接火山方舟，不使用其他图片模型代替。

**交付状态：本地接口测试已通过，真实豆包模型和宝宝照片验收待完成；未部署云端，未公开发布。**

## 先运行，不产生 API 费用

需要 Python 3.11+（推荐 3.12）与 pip。运行时仅依赖 Pillow 和 reportlab；SQLite 使用 Python 标准库。

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell 改为：.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py create-user --email your-email@example.com
python app.py serve
```

创建账号时密码在终端安全输入，至少 12 位，不会显示或写入配置文件。浏览器打开 **http://127.0.0.1:4173/**，用刚创建的账号登录。默认不开放注册，不发送邮件；邮箱在本 MVP 中是登录名，不表示已验证邮箱所有权。

未配置模型时可以上传照片、输入故事、得到明确标记的结构化初稿、选择 5/7/10 页、编辑并保存草稿。不会伪造 AI 整理或生成图片。

## 配置真实创作服务

只向服务端和 worker 进程提供以下环境变量，**不得放进 static、前端打包、公开仓库或截图**：

- `ARK_API_KEY`：火山方舟密钥，通过部署环境的秘密管理或本机安全环境设置。
- `ARK_TEXT_MODEL`：账号实际开通的豆包文本模型 ID/推理接入点；留空则使用结构化初稿。没有硬编码未经验证的文本模型。
- `JIGU_PAID_ENABLED=1`：仅在预算授权后开启。
- `JIGU_BUDGET_CNY`：本数据目录的累计预算上限，包含文字预留和图片预留；历史花费不会因为删书而清零。
- `JIGU_IMAGE_UNIT_CNY=0.12`：参考此前实验报告的图片单价估算，实际以账户账单为准。
- `JIGU_TEXT_RESERVE_CNY=0.05`：每次文字请求的保守预留，不是已确认的文字单价。应按选定模型和输入规模调整。

默认关闭付费且预算为 0。`.env.example` 仅作配置字段参考，直接运行 Python **不会自动读取 .env**。请通过安全的环境注入方式启动两个进程；不要把真实密钥写进命令历史。

配置完成后启动：

```bash
# 终端一（保持运行）
python app.py serve
# 终端二（使用相同的环境、JIGU_DATA_DIR；保持运行）
python app.py worker
```

用户确认故事之后才入队生图；后台 worker 逐页串行调用，刷新或关闭浏览器不影响任务。不要把 `serve` 本身当作后台绘画进程。

实际生图请求：

```json
{
  "model": "doubao-seedream-5-0-flash-260915",
  "size": "1776x2368",
  "response_format": "b64_json",
  "watermark": false,
  "prompt": "四段式画风 / 人物 / 本页 / 禁止清单",
  "image": ["data:image/jpeg;base64,<server-only>"]
}
```

不传 `sequential_image_generation`，不生成额外角色锚点。直接使用压缩后的原照片，每页独立调用。生成后检查图片数量和尺寸，再保存到私有文件目录。

## 工作流程

1. 登录 → 做一本小书。
2. 选择 1–6 张照片，输入真实经历、心情、细节、昵称、日期。
3. 整理故事，确认书名、每页文字和画面描述；可选择 5/7/10 页。
4. 在“每一页都想保留的小细节”锁定重要道具，例如紫色围巾。
5. 确认后开始绘画，查看真实任务状态。
6. 左右滑动、按钮或方向键翻页；修改文字、单页重画。
7. 重画先显示候选图，可以保留原图或接受新图。
8. 收好小书，下载含中文文字的整本 PDF，下次登录继续打开。

浏览器未提交的表单和压缩照片保存在当前账号名下的 IndexedDB 草稿；退出时清除本机该账号草稿。提交后的作品和进度以服务端为准。共用设备应在离开时退出。

## 可靠性与费用

- SQLite WAL、事务和唯一索引阻止同页同时入队；请求带幂等键。
- worker 进程持有独占锁，默认全局一次只调用一页。
- worker 重启时将上次正在执行的请求标记为 `uncertain`，**不会自动重发**；其余排队任务继续。
- 超时不代表没有扣费。核对火山账单之后，再在界面手动重试；每页最多 4 次调用（包含初次、失败和重画）。
- 单页重画保留原图，候选图被确认前不能再次重画。
- 费用账本保存模型、原始 usage、耗时、状态与保守费用预留。删作品不会清掉已发起调用的账本；尚未调用的队列预留可释放。
- 文本返回的 usage 也会保存；没有把 token 数换算成未经核实的“实付费用”。
- 无法从 API usage 独立确认账单折扣、退款和最终费用；本地预算是保守估算门槛，最终以供应商账单为准。

查看汇总：

```bash
python app.py costs
```

管理员重置密码（同时注销旧会话）：

```bash
python app.py reset-password --email your-email@example.com
```

## 数据与隐私

默认目录为项目下 `private-data/`，可用 `JIGU_DATA_DIR` 指向独立私有磁盘。目录不由 HTTP 静态服务器公开。所有图片读取、作品访问、编辑、生成、下载、删除均校验当前账号所有权。

上传照片在浏览器 canvas 重编码；后端再次解码、旋转、压缩并重编码，移除 EXIF。图片 ID 为随机值，但安全边界是服务端权限校验，**不是随机 URL**。API Key 只读环境变量。会话 token 服务端哈希保存，Cookie 为 HttpOnly、SameSite=Strict，写操作另校验 CSRF 和 Origin。登录有基础限频。

删除作品会删除参考照片、所有插图版本和关联任务；正在绘画时先等待当前页完成。已完成调用只保留不含照片、故事或提示词的费用记录。备份应由管理员按需要设置保留期；应用删除不等于供应商留存和外部备份也同步消失。

本地磁盘没有应用层加密。云部署时必须使用私有加密卷、HTTPS 和主机访问控制。**当前没有接入腾讯云 COS**；迁移到 COS 时需要私有桶、服务端鉴权读写，不应把目录直接改成公开图片地址。

## 私有部署准备（尚未实际部署）

提供 `Dockerfile` 和 `compose.yaml`。Docker 镜像仅复制生产代码，**不包含隔离界面测试服务器**。请先把 `.env.example` 复制为私密 `.env`，使用安全方式填入值，并设置严格文件权限；文件已列入忽略规则。

```bash
docker compose build
docker compose run --rm web python app.py create-user --email your-email@example.com
docker compose up -d
```

默认只绑定宿主机 `127.0.0.1:4173`。在远程服务器上可先通过 SSH 隧道私密体验；正式手机访问需要可信 HTTPS 反向代理 / VPN，并设置：

```text
JIGU_ORIGIN=https://your-private-domain.example
JIGU_SECURE_COOKIE=1
```

反向代理应限制请求体（至少允许压缩照片上传）、设置请求超时，并隐藏后端端口。标准库 HTTP 服务适用于本地/小规模私有试用；未做生产级负载和安全审计。不要直接将该进程裸露到公网。

持续存储挂载在 `/data`，web 与 worker 必须共享同一卷。不要将 SQLite 放到不支持可靠文件锁的网络文件系统。备份应使用 SQLite backup API，并同时备份 assets；先停 worker 再做全量迁移可避免图片与数据库不一致。

本工作环境没有适合此 Python 常驻 worker 的已配置私有云运行环境，因此没有创建 Sites 静态替代页，也没有公开发布。

## 测试

```bash
pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
# 如有 Node：
node --check static/app.js
```

接口测试使用临时目录、两个虚拟账号和程序绘制的色块；通过 mock 验证真实适配器的参数、状态变更和异常路径，**不会调用付费 API，也不证明豆包真人相似度或实际生成质量**。测试覆盖见 `docs/acceptance.md` 与 `docs/test-results.txt`。

`tests/visual_server.py` 是完全隔离、无真实照片的界面排版验收夹具。它省略登录，仅在临时数据目录里工作，**不得部署或作为生产启动入口**。图像为程序绘制的小鸟测试素材，不能当作豆包生成结果。
