V0 · 私有自用

把今天的小故事，
画下来。

上传几张宝宝的照片，说一句今天发生了什么。几分钟后，你会得到一本五页的成长小书——画的是她，写的是你们家的今天。

Structure

五页，讲清一件小事

不讲道理，不写成长报告。就是刚才那件事：怎么开始的，发生了什么，哪一句话最想记住，最后你心里是什么感觉。

  1. 封面书名，加一张她的半身近景。
  2. 故事开始时间、地点、那天的小状况，一句话交代清楚。
  3. 发生的事情她做了什么。要能看见动作，不是「她很开心」。
  4. 最值得记住的细节那句话，那个动作，原样留下来。
  5. 结尾你当时的感受，收在一句轻的话里。
Flow

先看文字，再画图

文字没确认之前，不会调用任何一次画图。省下来的不只是钱，还有你返工的时间。

  1. 传照片1–6 张，建议 2–4 张：看得清脸，也看得清当天的衣服和配饰。
  2. 讲故事三句话：发生了什么、当时的感受、想记下来的细节。
  3. 改文字五页文字和画面描述都会给你看，点着就能改，书名也能改。
  4. 逐页画确认后逐页生成。哪一页不满意就单独重画，其他页不动。
Look

像一本真的小书

暖白纸底，低饱和的浅杏、雾蓝、草绿。水彩和彩铅的手绘质感，线条圆但不幼稚，留白多，光很轻。

机位要有远近

封面偏近，后面几页中景、全身交替，能看到沙发、地板和她站着的整个样子。不是五张一样的大头照。

整本同一个人

脸型、发型、当天的衣服和配饰，每页都锁住。画风统一，构图变化。

画面里没有字

字由程序排上去，位置、字号、行距都可控。图上不会出现歪歪扭扭的 AI 文字。

不画不该有的东西

故事里没有的人、动物、玩具、道具一律不出现。发烧就是发烧，不会变成吃药和体温计。

Privacy

照片只留在你自己的电脑上

  • 照片上传后重新编码，剥掉 EXIF：GPS、机型、拍摄时间都不保留。
  • 文件存在本机 data/ 目录，画图时以 Base64 直接发给火山方舟，不经过任何公网图床。
  • API Key 只从服务端环境变量读取，不进前端、不进日志、不进仓库。
  • 删除作品时，连图片文件一起删掉，不留副本。
Run

三行命令，本地跑起来

pip install -r requirements.txt
setx ARK_API_KEY "你的火山方舟 Key"
python run.py

浏览器打开 http://127.0.0.1:7860，就是手机上的样子。一本五页按量计费，约 0.6 元，重画一页 0.12 元。

这是一个带密钥的 Python 服务端，不能托管在 GitHub Pages 上。这个页面只是产品介绍，真实生成必须在本机跑。
Scope

V0 故意不做的事

没有社区，没有点赞关注，没有自由创作模式，没有复杂编辑器，没有多画风，没有 AI 配音，没有打印和支付，也不做多宝宝。

也没有自动质检。宝宝像不像、场景对不对，机器不打分——你看一眼，说一句「不像」或「换个画面」，就重画那一页。
