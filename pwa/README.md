# 叽咕插画 PWA

与叽咕一下相同的暖白底色、系统中文黑体、克制字号。产品前端部署到 GitHub Pages，访问 `https://vanesacoding.github.io/jigu-picturebook/`，可添加到手机主屏幕。

## 当前可以体验

- 首页、故事表单、1–6 张照片、缩略图和删除。
- 浏览器 canvas 重新编码照片，去除 EXIF、压缩到 600KB 以内。
- IndexedDB 保存照片 Blob、故事草稿、5/7/10 页文字与画面描述；刷新后恢复。
- 明确标注的原文初稿，每页可编辑；支持文字版翻阅、左右滑动、键盘翻页、单页文字修改。
- 双列本机书架，打开和删除；叽咕一下绘本入口。
- 虚构人物的排版示例、整本示例 PDF；示例各页复用同一张插画，文件与页面均标注，不是豆包真实出图。
- manifest、应用图标、service worker；首次在线打开后，缓存应用壳与示例素材。真实离线访问及安装需 HTTPS 和浏览器支持。

## 当前未开通

**发布版本的 `docs/config.js` 中 cloudEnv 为空，未部署真实云端，不会发验证码、上传照片、调用豆包或收费。** 开始绘画会明确提示服务正在接入并保留草稿。没有模拟进度或假装生成宝宝插画。

GitHub Pages 只能托管静态前端，不能安全保存方舟 Key、验证付费、处理后台生图。后端沿用同一仓库的 `wechat-miniapp/` CloudBase 服务，现已增加可信 Web UID 身份适配；前端对接 CloudBase 官方 Web SDK 的邮箱 OTP、私有作品 API、真实任务查询、单页重画与候选图、完成作品 PDF。**这些真实云端能力尚未做账号联调。** 网页版付费购买暂不开放，服务端主动拒绝 Web 用户创建小程序 JSAPI 订单，不能把小程序支付参数用于 PWA。

首本 5 页免费、之后按本定价 ¥3.9/5.9/7.9 的产品决策保留。首次免费按各产品账号核验，跨小程序/Web 合并账户和福利需要额外受信身份关联，不自动合并。

## 后端连接

1. 按 `wechat-miniapp/README.md` 部署数据库、私有对象存储、api/generator/ops/payNotify 云函数和权限规则。腾讯云存储不得公开读。
2. CloudBase 身份认证开启邮箱验证码登录和正常的风控，配置 `https://vanesacoding.github.io` 为安全域名。
3. 服务端配置 ARK Key、可用的文本模型、已获准的累计预算；付费接口默认关闭。Key 只在服务端，不放 GitHub、config.js 或浏览器输入框。
4. `docs/config.js` 只填写公开 `cloudEnv` / region。SDK 登录后 `api` 用运行时可信 UID 获取账户，拒绝没有邮箱身份的匿名请求，不接受客户端指定 owner。
5. 浏览器端的云端图片需要正确的 COS CORS（允许本站 GET 与 canvas 导出），签名 URL 不进入 service worker 缓存。
6. 在体验账号验证登录、两用户隔离、首次免费、真实五页生图、任务刷新恢复、原图保留、删除和 PDF 后再开放给真实家长。需填运营方隐私指引与联系方式。

## 隐私和本机草稿

未接云时照片完全留在当前设备；公开仓库只有源码、图标与虚构示例。草稿存在浏览器存储中，**不等于跨设备云备份或加密保险箱**：同一浏览器共用设备的人可以访问本机草稿；清理数据、浏览器回收空间或卸载后可能丢失。云端作品与当前账号隔离，本机草稿在确认创作时才上传。
