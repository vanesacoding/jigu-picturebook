# 与叽咕一下统一的文字规范

参考原产品仓库 `vanesacoding/say-it-today`，读取 `index.html` 提交 `69e5c2d307ec5a2083d49cc32c818101f12b1796`（2026-10-21）。不修改原产品。

原产品字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans CJK SC", sans-serif`。叽咕插画沿用，不下载花体或额外字体，不对中文使用宋体，不拉开标题字距。原产品英文阅读用 Georgia，插画产品没有对应的英文正文需求。

原产品暖白 `#faf7f1`、正文 `#352c28`、辅助 `#8c7e73`、分隔 `#eee8e0` 同步使用。强调按钮保留用户指定的杏色 `#eac5a5`。

| 用途 | 插画小程序 | 375px 视口近似 | 字重 |
|---|---|---|---|
| 品牌 | 38rpx | 19px | 700，仅品牌 |
| 页面标题 | 44rpx | 22px | 600 |
| 书名、段落标题 | 30–32rpx | 15–16px | 500–600 |
| 表单、按钮、正文 | 28rpx | 14px | 400–600 |
| 辅助说明 | 24–26rpx | 12–13px | 400 |
| 日期、页码 | 20–22rpx | 10–11px | 400 |
| 绘本短句 | 32rpx | 16px | 400，1.8 倍行高 |

按钮点击高度至少 88rpx（约 44px），没有为了小字号缩小点击区域。文字较长时书页字号 26rpx，允许滚动；建议确认页将每页控制为 1–2 句。PDF 按同样的系统无衬线排版并栅格化，以免缺少中文字体。

字号的最终验收还需要真实微信设备：320/375/430px 宽度、iOS/Android、系统放大字体，重点看文字截断和书页可读性。这里不声称完成原生模拟器或真机视觉验收。
